# Mamta Pickles Web Client

Modern React + Vite frontend for Mamta Pickles online store.

## Features
- Authentic branding and responsive UI
- Interactive pickle product catalog with category filtering & search
- Weight options selection & price updates
- Shopping cart drawer with free shipping progress bar
- Razorpay Online Payment & Cash on Delivery (COD) checkout modal
- JWT Authentication (Login / Register modals)
- Customer order history tracking

## Development
```bash
npm install
npm run dev
```
Runs at `http://localhost:3000`.
