# Mamta Pickles Web Client

Single Page Application (SPA) built with React 19, Vite 6, and custom CSS design system.

## Key Modules
- Interactive product catalog with dynamic jar weight pricing.
- Slide-out cart drawer with real-time free shipping threshold tracking.
- Razorpay payment checkout integration and Cash on Delivery option.
- User authentication modals for Sign In and Account Registration.
- Customer order history tracking and Store Administrator Dashboard.

## Local Execution
```bash
npm install
npm run dev
```
Client runs at `http://localhost:3000`.

## Production Build
```bash
npm run build
```
Compiled output saved in `dist/`.
